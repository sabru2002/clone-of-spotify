# Spotify Clone

A responsive music player website inspired by Spotify, built using HTML, CSS, and JavaScript. This project provides a simple and interactive music streaming experience with music controls and a clean user interface.

## Features

* Responsive music player interface
* Play and pause music
* Previous and next song controls
* Progress bar for seeking through songs
* Volume control
* Song list with music selection
* Displays the currently playing song
* Clean and user-friendly design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How It Works

1. The user selects a song from the music list.
2. JavaScript loads the selected audio file.
3. The user can play, pause, or change the song.
4. The progress bar allows the user to seek through the audio.
5. The next and previous buttons control song navigation.

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/spotify-clone.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Select a song and enjoy the music player.
